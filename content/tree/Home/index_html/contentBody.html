This site is built by Astro from a content tree: a directory tree under content/tree/ whose nodes are this site's pages. It is the model of the ByStar Plone 3 ContentTree, carried over: the same node types and the same parameter files, so the content of the Plone 3 sites moves here nearly unchanged.

Start a site by copying this repository. Then:

  • replace content/tree/ with your own tree (or import a Plone 3 ContentTree);
  • set the fqdn and dev port in astroProc.spcs, and rename the files in cbm/;
  • build with ./astroProc.spcs -i siteBuild.

See The Content Tree for the model and Building and Serving for the commands. فارسی is a right-to-left page.
