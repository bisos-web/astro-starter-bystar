objectTypeWhat it is
foldera section; its page is its index_html/ leaf
pagea page; its body is contentBody.html
pageLcnta page whose body is built from an LCNT document by HeVeA
filesfiles placed in the site at siteFolder
customsite-specific (e.g. the Plone 3 sites' lcntLists)
linka tab that leads out (linkUrl, opened in a new tab), e.g. to another .here site
appthe tree gives the tab, title and place; a fixed page at that path (site/src/pages/<path>.astro) renders it, e.g. a React application as an island

The Plone 3 sites' slider nodes (auxNode, auxLeaf, rawFiles) are skipped; Reveal presentations replace them.
